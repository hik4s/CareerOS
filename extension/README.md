# Extensão Career OS

1. Abra `chrome://extensions` ou `edge://extensions`.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione a pasta `extension`.
5. Fixe a extensão na barra.
6. Inicie o Career OS, abra uma vaga e clique em **Capturar vaga atual**.

A extensão usa `activeTab`, portanto lê somente a aba onde você clicar. Ela não envia candidaturas nem lê senhas.
